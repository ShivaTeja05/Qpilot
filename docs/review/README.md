# Independent review of the Decision Simulator (17-18 Oct 2026)

Nine AI research agents reviewed the simulator in three stages:

- **Research.** Four agents each searched a different part of the internet: lab practice, Clarida and other competitors, theoretical simulators, and validation datasets.
- **Debate.** An advocate and a skeptic argued over two rounds, each rebutting the other.
- **Ruling.** A judge, written as an experienced qPCR core-facility head who knows statistics, decided the contested points.

Each file is the agent's output, unchanged. Claims carry URLs; items an agent could not open are marked UNVERIFIED. Numbers in the debate may predate later fixes. The ruling lists the figures it checked.

| File | Content |
|---|---|
| 00-judge-ruling.md | Verdict, scorecard, who won each point, Clarida comparison, ranked changes, validation plan, 12 hardest questions |
| 10–13 | Advocate and skeptic openings and rebuttals |
| 20–23 | Research reports: lab practice, Clarida and competitors, theoretical simulators, validation data |
