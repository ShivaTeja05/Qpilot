## NOTE 04 — Pre-analytics and QC gates for RT-qPCR (sample quality, RT, inhibition, gDNA, controls)

### A. How this corner works

The bench scientist extracts RNA, measures it on a NanoDrop and/or Qubit, sometimes sends it to a core for a TapeStation/Bioanalyzer run (RIN/RINe/RQN/DV200), DNase-treats (or not), reverse-transcribes a fixed RNA mass, dilutes the cDNA and runs plates. The QC numbers live in a core PDF, a CSV on a shared drive or a notebook and are rarely joined to the Cq table; the PI answers reviewers' MIQE questions from memory; core managers get "why did my run fail?" without the client's qPCR data; only enterprise LIMS engineers build connectors (Benchling publishes guides and open-sourced the MIT allotropy parsers, https://github.com/Benchling-Open-Source/allotropy).

Each step moves Cq. Room-temperature PBMC RNA fell from RIN 9.3 to 3.78 over 84 h (https://pmc.ncbi.nlm.nih.gov/articles/PMC4071332/). Degradation shifts Cq by roughly 0.1–1.6 cycles per RIN unit depending on gene/tissue/amplicon, and expression-ratio error reaches ~100% at RIN ≈ 5 (https://gene-quantification.de/fleige-et-al-rna-integrity-2006.pdf; https://gene-quantification.de/ho-pun-cheung-rin-algorithm-2009.pdf). Only 6% of researchers test for inhibitors (https://www.soihub.org/modules/Data_Quality_Modules/DQ_refs/qPCR_refs/Nolan_2006.pdf). RT is the single largest technical variance source: 2–3-fold apparent differences between RT replicates of the same RNA, up to ~7-fold (https://gene-quantification.com/bustin-et-al-rt-variability-clin-chem-2014.pdf). Uncorrected efficiency distorts fold changes by 20–40% (https://www.gene-quantification.de/bustin-wittwer-rt-qpcr-reporting-standards-clinical-chemistry-2026.pdf), all larger than the 1.2–1.5-fold changes commonly reported as meaningful (https://pmc.ncbi.nlm.nih.gov/articles/PMC12154065/).

Money: Qubit RNA HS kit £103/100 assays (https://www.thermofisher.com/order/catalog/product/Q32852); TATAA Universal RNA Spike I €296.89–934.10 (https://webshop.tataa.com/products/tataa-universal-rna-spike-i); Thermo Xeno spike £748 for 5 × 200 µL (≈ £7.5/sample) (https://www.thermofisher.com/order/catalog/product/A39179); ValidPrime kits €225.82–657.07 (https://webshop.tataa.com/products/validprime%C2%AE); ERCC mix £1,251.65 (https://www.thermofisher.com/order/catalog/product/4456740). Per-sample TapeStation/Bioanalyzer cost "a few € per sample" is the note's own estimate, not sourced. Reporting of the checkable items is collapsing: RNA integrity 22% → 11% (2019 → 2024), efficiency 13% → 1% (https://www.gene-quantification.de/bustin-wittwer-rt-qpcr-reporting-standards-clinical-chemistry-2026.pdf). RDML 1.3 already has fields for all of this (sample `type` incl. `nrt/ntc/nac`, `cdnaSynthesisMethod`, `templateQuantity`, `annotation`) but vendor exports rarely populate them (https://github.com/RDML-consortium/rdml-schema).

### C. Discoveries

**D1. Per-sample "fitness-for-analysis dossier" from instrument QC exports joined to the study's curves** (rank 1)
- Persona: PhD student/core client with NanoDrop/Qubit + core TapeStation/Bioanalyzer run, analysing 6–12 plates; core manager asked "why did these three fail?". Every study.
- Pain evidence: RNA integrity reported in 11% of 2024 papers (https://www.gene-quantification.de/bustin-wittwer-rt-qpcr-reporting-standards-clinical-chemistry-2026.pdf); Cq moves 0.04–1.6 cycles per RIN unit (https://gene-quantification.de/fleige-et-al-rna-integrity-2006.pdf); quality predicted misclassification OR 4.65, "normalization did not fully remove the effect" (https://pmc.ncbi.nlm.nih.gov/articles/PMC3089491).
- Exists today: Benchling/SLIMS connectors (paid, no qPCR link); allotropy (MIT; no Bioanalyzer/ProSize parser; RINe only as generic calculated value); bioanalyzeR (R, MIT, computes DV200, no qPCR link); Clarida scores MIQE from Cq tables only. Nobody joins QC file to plate.
- Feature: inputs TapeStation XML (+Electropherogram.csv), Bioanalyzer XML, ProSize CSV bundle, NanoDrop One/Eight CSV, Qubit CSV/XLSX, Lunatic CSV/XLSX (headers documented in note §1.3). Method: parse to canonical `SampleQC` facts with file hash; join to RDML sample ids by name with human-confirmed mapping; editable rule pack (RIN ≥ 5 min / ≥ 8 optimal; RIN < 7 high-variance; DV200 bands; A260/230 < 1.8; UV/dye ratio > ~1.5; amplicon > 200 bp on RIN < 8; oligo-dT on RIN < 7); study-derived integrity model regressing reference-gene Cq and normalisation factor on RIN (Fleige/Vermeulen regression, https://gene-quantification.de/fleige-et-al-rna-integrity-2006.pdf) plus RIN-by-group confounding test (https://pmc.ncbi.nlm.nih.gov/articles/PMC4071332/); optional 3′/5′ index 2^(Cq5′−Cq3′), ratio 8 ≈ RIN 5 (https://pmc.ncbi.nlm.nih.gov/articles/PMC6006387/). Decision: include/exclude/adjust per sample. Record: QC facts, mapping, rule-pack version, MIQE 2.0 Section 2 auto-fill. Agent: `qpcr_sample_qc(study)`, `qpcr_fitness(sample_id)`, `qpcr_import_qc(file)`.
- Feasibility: allotropy test files + bioanalyzeR source (both MIT); parsers ~1–2 weeks; DV200 from traces ~1 week; mapping UI 1 week; regression/cards 1–2 weeks. Hardest: name matching, and no public corpus pairing QC exports with RDML plates.
- Why qPilot: already holds curves, efficiencies, reference-gene stability, robustness grid; two more grid axes; amplicon lengths from RDML `sequences`.
- Risks/confidence: RIN is rRNA-based, mRNAs degrade differently; thresholds tissue-specific; over-exclusion reduces power. Confidence: **high** for dossier/auto-fill, **medium** for the impact model.

**D2. Inhibition gate from curve kinetics plus spike-ins, with dilution-series artefact detector** (rank 2)
- Persona: FFPE/blood/stool/soil/plant researchers; diagnostics-adjacent labs running SPUD/Xeno/TATAA; core manager with "no amplification" complaint.
- Pain evidence: only 6% test for inhibitors; FFPE up to 30% inhibited (https://www.soihub.org/modules/Data_Quality_Modules/DQ_refs/qPCR_refs/Nolan_2006.pdf); SPUD inhibited in 1/19 urine extracts vs target in 15/19 (https://europepmc.org/article/PMC/PMC2564953); SOD sensitivity 0.93–1.00 vs KOD 0.30–0.76 (https://pmc.ncbi.nlm.nih.gov/articles/PMC2873533/).
- Exists: qpcR implements KOD/SOD/ACT but GPL-2/3 (https://ftp.fau.de/cran/web/packages/qpcR/refman/qpcR.html); vendor software reports slope/R² only; LinRegPCR uses amplicon-mean efficiency, no per-well flag.
- Feature: inputs raw `adp`, LinRegPCR per-well efficiency, RDML well types, spike wells annotated `spike=SPUD|Xeno|TATAA`, optional dilution series. Methods (reimplemented, not copied): (i) KOD Z-test α 0.05 (https://europepmc.org/abstract/MED/12930979); (ii) SOD 5-parameter Richards fit, Mahalanobis, χ²(3) > 7.81 (https://pmc.ncbi.nlm.nih.gov/articles/PMC2873533/); (iii) quenching flag (plateau low, Cq/slope normal); (iv) spike rule ΔCq > 1 same run/threshold; (v) standard-curve artefact: efficiency > 110% or slope shallower than −3.1 with concentration-trending residuals → "inhibitor dilution-out suspected"; (vi) differential-susceptibility caveat. Output per sample × assay: inhibited/suspect/clean with p-values. Decision Card: exclude wells / dilute 1:5 and rerun / keep with flag. Agent: `qpcr_inhibition(study, method=SOD|KOD|ACT|spike)`.
- Feasibility: numpy/scipy; KOD 2–3 days, SOD 1–2 weeks, ACT 1 week. No public labelled inhibited-curve dataset — note proposes building one (tannic acid, humic acid, IgG titrations at Sisti's concentrations) and publishing CC0; Brintz 2025 may provide negatives. Hardest: false positives at low copy; TaqMan lacks quenching so (iii) must be chemistry-aware.
- Why qPilot: per-well efficiency and raw curves exist; detectors are versioned method modules with public acceptance tests; robustness reruns.
- Risks/confidence: KOD alone under-detects (ship SOD/ACT primary); flag = kinetic anomaly, not proof of inhibitor; spike clean ≠ target clean. Confidence: **medium-high**.

**D3. gDNA contribution per gene from no-RT wells, ValidPrime-style correction and grades** (rank 3)
- Persona: anyone targeting intronless genes or pseudogene-rich references (GAPDH, ACTB); labs skipping DNase; anyone staring at a no-RT well 6 cycles behind.
- Pain evidence: MIQE 2.0 asks "estimated copies measured with and without addition of RT" (https://www.multid.se/publications/MIQE-ver2.pdf); ValidPrime grades A < 3%, B 3–25%, C 25–60%, F > 60% uncorrectable (https://pmc.ncbi.nlm.nih.gov/articles/PMC3326333/); rules of thumb 5–7 and 10 cycles (https://bitesizebio.com/37844/control-qrt-rtpcr/).
- Exists: ValidPrime kits €226–657 with GenEx 5.3 or gh-validprime ("free for academic use"); otherwise mental arithmetic.
- Feature: inputs `nrt`-typed wells with same sample id, optional VPA wells and gDNA standard, LinRegPCR mean efficiency. Method: f = E^−(Cq_nrt − Cq_rt); grade by ValidPrime bands; with VPA, compute GOI gDNA sensitivity, subtract RQ_gDNA from RQ_total, require ΔCq SD ≤ 0.3 criterion; propagate uncertainty to N0 (https://pmc.ncbi.nlm.nih.gov/articles/PMC3326333/). Decision Card per gene: subtract / exclude samples / drop GAPDH as reference (geNorm rerun) / accept; grid axis corrected vs uncorrected. Auto-fills MIQE 2.0 RT item. Agent: `qpcr_gdna(study)`. Design hook: `qpilot plan` places no-RT per sample at first extraction, then per batch, or m + n + 1 ValidPrime controls.
- Feasibility: arithmetic; one week. Hardest: layout capture (vendor exports rarely mark no-RT wells); intron-spanning status not derivable from RDML; ValidPrime patent application seen only in search summary — check before commercial packaging.
- Why qPilot: reference-gene choice, per-gene consequences, robustness are native.
- Risks/confidence: assumes equal efficiency RT(+)/no-RT; no-RT well contamination; low-copy noise at Cq 35+ (LLOQ ≈ 10 copies). Confidence: **high**.

**D4. Negative-control ledger: dimer-vs-contamination classification and contamination trending** (rank 4)
- Persona: student whose NTC lit up at Cq 32; lab manager suspecting a contaminated water bottle or primer lot; core with no cross-run memory.
- Pain evidence: MIQE 2.0 5-cycle rule and "frequency and Cq of negative controls" item (https://www.multid.se/publications/MIQE-ver2.pdf); preprint NTC Cq 25.97 with product Tm → contamination (https://www.biorxiv.org/content/10.1101/2025.08.07.669038v1); dimers melt 65–75 °C vs amplicons 78–88 °C (https://azurebiosystems.com/qpcr-troubleshooting-workflow/).
- Exists: vendor shows NTC curve and melt peaks; no ledger, control chart, or computation of the MIQE item.
- Feature: inputs `ntc/nac/nrt` wells, `mdp` melt data, per-run product Tm from positive wells of same assay/run (never a fixed literature Tm), run date, instrument serial, lot annotations. Per run: NTC Cq, ΔCq to lowest unknown, melt class (dimer if peak ≤ Tm_product − 3 °C; contamination if within ~2 °C), 5-cycle rule on every unknown. Across runs: NTC positivity rate, Shewhart limits on NTC Cq, run-length rule, change-point alignment with lot annotations. Decision Cards: invalidate run / exclude samples within 5 cycles / accept dimer-type NTC. Agent: `qpcr_controls_ledger(lab, assay)`.
- Feasibility: melt-peak calling 1 week; ledger/chart 1 week. Test data: qPilot's RDML corpus (NTC wells present in most files). Hardest: cross-instrument Tm (solved within-run) and persuading users to record lots.
- Why qPilot: melt data, typed wells, persistent store ("lab memory") already on roadmap.
- Risks/confidence: probe assays give no melt class; late dimers common → impact-rank to avoid approval fatigue. Confidence: **high**.

**D5. The RT step as a first-class covariate: capture, variance decomposition, confounding check, RT-replicate planning** (rank 5)
- Persona: any lab reporting fold changes < 3; student who RT'd treated samples Monday and controls Thursday; core processing 200 samples in batches; lab head choosing an RT kit.
- Pain evidence: RT replicate ΔCq ranges 0.4–1.74 cycles; 25% of RT-replicate fold changes > 3-fold; RT in duplicate "remains unheeded" (https://gene-quantification.com/bustin-et-al-rt-variability-clin-chem-2014.pdf); "most experimental variation came from the reverse transcription step" (https://europepmc.org/abstract/MED/14726469); audits: RT replicates "No information" in essentially every paper (https://europepmc.org/abstract/MED/28796277).
- Exists: powerNest (licence unverified), GenEx nested ANOVA (commercial); RDML `cdnaSynthesisMethod`/`templateQuantity` fields that no importer populates.
- Feature: (a) one-screen RT form writing RDML `cdnaSynthesisMethod`, `templateQuantity`, annotations `rt_batch`, `rt_date`, `rna_input_ng`, `cdna_dilution`, `extraction_batch`, `operator`, `reagent_lot`, importable from CSV; (b) design checks: constant RNA input, cDNA ≤ ~5% v/v or ≥ 1:5 dilution (https://pmc.ncbi.nlm.nih.gov/articles/PMC1298932/), priming vs integrity; (c) nested ANOVA sample/RT/PCR (https://www.labgenexp.eu/publications/design-and-optimization-of-reverse-transcription-quantitative-pcr ; https://europepmc.org/abstract/MED/20109551) vs Bustin benchmark ΔCq < 1; (d) confounding crosstab group × rt_batch × extraction_batch × plate; (e) mixed model with random batch effects; (f) `qpilot plan` recommends RT replicates under budget. Decision Card e.g. "RT batch explains 22% of variance; group A in batch 1 only — confounded". Agents: `qpcr_rt_variance(study)`, `qpcr_confounding(study)`.
- Feasibility: statsmodels (BSD) 1–2 weeks; form/import 1 week. Hardest: nobody records RT batches today — form must be a 30-second task.
- Why qPilot: decision log, per-gene consequences, grid, plan command, RDML fields, MCP for LIMS push.
- Risks/confidence: low value without metadata; without RT replicates the deliverable is the confounding check plus a "fold changes below 3 are within RT noise" caveat. Confidence: **medium**.

**D6. QC-ready plate design rules in `qpilot plan` plus MIQE 2.0 Sections 2/3/5 auto-fill map** (rank 6)
- Persona: whoever designs next week's plates; first author filling the MIQE table; Clin Chem-style reviewer.
- Pain evidence: audits (https://www.gene-quantification.de/bustin-wittwer-rt-qpcr-reporting-standards-clinical-chemistry-2026.pdf); design rules with numbers: NTC per assay per plate, one −RT per extraction batch, positive control ± 1 cycle, IPC ± 0.5–1 Ct (https://bitesizebio.com/37844/control-qrt-rtpcr/); amplicon ≤ 200 bp, ideally 80–150 bp (https://gene-quantification.de/fleige-et-al-rna-integrity-2006.pdf), < 100 bases for FFPE (https://pmc.ncbi.nlm.nih.gov/articles/PMC1602211/); in-sample internal control at 3–10× LOD (https://www.multid.se/publications/MIQE-ver2.pdf).
- Exists: Clarida MIQE score (Cq input, questionnaire); checklist as editable table; vendor plate-design assistants (layouts only).
- Feature: `qpilot plan` "QC-ready layout" option emitting typed wells (ntc per assay, nrt per extraction batch, pos, std series, interRunCalibrator, spike-in-water control, VPA + gDNA standard) and writing RDML sample types/annotations so D2–D5 are checkable; assay rule check (amplicon vs sample type, priming vs integrity, pseudogene flag). End of study: MIQE 2.0 renderer fills every machine-checkable item from engine facts plus two short human forms, marks the rest "not recorded", exports Yes/No table — the "MIQE-derived module" Bustin & Wittwer ask for. Agents: `qpcr_plan(qc_ready=true)`, `qpcr_miqe(study)`.
- Feasibility: layout logic 1 week; renderer 1 week; the KQ5 machine-checkability map is the specification. Hardest: not over-constraining plates.
- Why qPilot: plan, record, decision log, domain-agnostic core exist; checklist renderer is a roadmap headline.
- Risks/confidence: mandated controls may feel like nagging (keep optional with consequences); MIQE 2.0 table format may change. Confidence: **high**.

## NOTE 05 — Instruments, vendor software, file formats, APIs and data standards

### A. How this corner works

Every instrument produces one fluorescence reading per well, per filter/dye, per cycle, then hides it behind a vendor container and analysis layer. The scientist touches the path at four points: plate setup, the run (native file lands on instrument PC/USB/share/cloud), a GUI export whose menu choices decide whether raw, normalised or baseline-subtracted values come out, and analysis. Integrators (Benchling, TetraScience, Ganymede) hook the export folder, not native files (https://help.benchling.com/hc/en-us/articles/21443044938637 ; https://www.tetrascience.com/blog/worlds-largest-fastest-growing-purpose-built-library).

"Raw" means something different per vendor. Thermo exports three layers — Raw (per filter, not ROX-normalised), Multicomponent (per dye incl. passive reference), Amplification (Rn/ΔRn) (https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN0010409_QuantStudio_CLA_UG.pdf ; https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN0018200_QuantStDesgnAnalysisSW_v2_Desktop_UG.pdf). Bio-Rad CFX Maestro's RFU export inherits whichever baseline mode is active ("No Baseline Subtraction", "Baseline Subtracted", "Baseline Subtracted Curve Fit"), so it is raw only if the analyst switched mode first; `.pcrd` is encrypted (https://www.bio-rad.com/sites/default/files/webroot/web/pdf/lsr/literature/10000126764.pdf). Roche LC480 `.ixo` stores instrument units scaled on export by `ScalingFactor/(RefValue×IntgrTime)` (https://raw.githubusercontent.com/openreadout/openreadout/main/crates/openreadout-qpcr/src/ixo.rs). Qiagen `.rex` keeps raw readings only (https://raw.githubusercontent.com/openreadout/openreadout/main/crates/openreadout-qpcr/src/rex.rs). RDES demands values "raw, corrected only for machine background, with no baseline correction and no negative values" (https://raw.githubusercontent.com/RDML-consortium/rdml-schema/main/RDES_v1_0_REC.txt).

Standards: RDML 1.3 is REC, 1.4 still Candidate Release (https://github.com/RDML-consortium/rdml-schema); rdmlpython on PyPI is 1.7.2 (22 May 2023) while GitHub 2.0.x (24 Jan 2024) adds RDML 1.4/Ncopy/GeNorm (https://pypi.org/pypi/rdmlpython/json ; https://raw.githubusercontent.com/RDML-consortium/rdmlpython/main/RELEASE_NOTES.txt). Allotrope ASM qPCR schemas are cut quarterly 2021/12–2026/09 but licensed CC BY-NC / CC BY-ND / member licence (https://gitlab.com/allotrope-public/asm/-/raw/main/LICENSE.md). SiLA 2 has no qPCR feature or driver (https://gitlab.com/SiLA2/sila_base). Thermo instrument API access "is exclusive to authorized OEM partners" (https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN0017853_QS1_UG.pdf).

## NOTE 06 — Between the optics and the Cq: raw-signal processing, plate-position and instrument artefacts

### A. How this corner works

Four vendor pipelines transform the camera signal through steps that are documented in outline only. Thermo: "Raw data → Multicomponent → Rn → Ct", with multicomponenting using pure-dye and background calibrations and Rn = reporter / passive reference (https://orthofacilities.su.domains/wp-content/uploads/2021/09/Stanford-QS6Pro-Orientation-0222021.pdf); calibrations (ROI, background, uniformity, dye, normalization) are stored per instrument and copied into every `.eds`; dye calibration "at least every 6 months" because "the age and use of instrument components can affect spectra readings" (https://documents.thermofisher.com/TFS-Assets/LSG/manuals/4489821.pdf). Bio-Rad: no passive reference; software "automatically subtracts the baseline from well data" (https://www.bio-rad.com/webroot/web/pdf/lsr/literature/10014294.pdf); kit protocols lock "Baseline Subtracted Curve Fit" (https://cdnmedia.eurofins.com/european-east/media/1230356/biorad_cfx96_touch_applicationnotes.pdf). Roche LC480: colour compensation and a choice between second-derivative Cp and Fit Point; the two differ by 1.2 (±0.5) cycles, efficiencies 104.4% vs 137.3% (https://pmc.ncbi.nlm.nih.gov/articles/PMC7151141/). Qiagen Rotor-Gene: dynamic-tube normalisation and "Slope Correct" unless deselected (https://www.bdrdiagnostics.com/wp-content/uploads/2023/09/Rotor-Gene-Q-Manual-ENG-2022_Rev01.pdf).

Position and instrument effects are real: 96-replicate Ct SD 0.34 on a CFX96 vs 1.91 on an ABI 7900HT; uniformity specs ±0.4–0.5 °C vs Rotor-Gene ±0.02 °C (https://pmc.ncbi.nlm.nih.gov/articles/PMC4578049/). Cross-platform offsets of 4–5 cycles for the same samples (https://pmc.ncbi.nlm.nih.gov/articles/PMC7151141/); inter-laboratory > 6 cycles (https://academic.oup.com/clinchem/article/68/1/153/6385233) and up to 14 cycles across methods (https://academic.oup.com/cid/article/72/10/e685/5891762); "6-times difference between runs 2 and 5" in a routine multi-plate experiment (https://www.gene-quantification.de/ruijter-et-al-variation-multi-plate-pcr-bdq-2015.pdf).

Money and time: Thermo RNase P verification plates $1,136 / $1,178 / $1,508 (single-use), ROI/background plates $369–374, spectral plates $426–696, calibration install kits $3,100–3,180 (https://www.thermofisher.com/us/en/home/life-science/pcr/real-time-pcr/reagents-kits/other/calibration-verification.html); GBP 876, "every six months" (https://www.thermofisher.com/order/catalog/product/4432382). Verification frequency GMP every 6 months, CAP/CLIA annually at minimum (https://www.femtoscientific.com/thermal-cycler-pcr-rtpcr-calibration-service-repair-thermal-verification). Vendor QC answers only pass/fail per instrument; Thermo's software "automatically adjusts the threshold and omits a defined number of wells" (https://www.ffclrp.usp.br/divulgacao/emu/real_time/manuais/QuantStudio3_5_InstallUseMaint_UG.pdf). Clinical labs trend with Levey-Jennings/Westgard (https://www.westgard.com/mltirule.htm; https://www.ugentec.com/fastfinder); research labs have nothing. Re-run cost estimates are the note's own (labelled).

### C. Discoveries

**D1. "Is this curve raw?" — signal-provenance guard before LinRegPCR runs** (rank 1)
- Persona: postdoc exports a CFX Maestro run (defaults) or a QuantStudio "Amplification Data" sheet and loads it into qPilot. First use of every new instrument/software version; estimate once per lab per month, silently weekly.
- Pain evidence: CFX exports baseline-corrected by default; fix is forum knowledge (https://www.researchgate.net/post/Has_anyone_sucessfully_exported_raw_data_from_BioRad_qPCR_files_to_conduct_analysis_using_LinRegPCR_or_other_programs); QuantStudio Ct "already ROX-normalized (derived from ΔRn, not raw Rn)" (https://voilapcr.com/blog/how-to-export-and-analyze-quantstudio-qpcr-data); Ruijter 2015 pipeline "starts with raw fluorescence values" (https://www.gene-quantification.de/ruijter-et-al-variation-multi-plate-pcr-bdq-2015.pdf); Spiess 2008 used data "not processed (i.e. baseline corrected)" (https://doi.org/10.1186/1471-2105-9-221). Cost estimate: a full study re-analysed, or published wrong.
- Exists: nothing — rdmlpython, LinRegPCR, qpcR, PCRedux accept whatever numbers they get.
- Feature (the "is this curve raw?" tests): input per-cycle matrix (RDML `adp` or vendor sheet) + declared source. Deterministic tests each yielding a fact with confidence: (a) ground-phase offset — raw curves have positive offset (RFU hundreds–thousands on CFX; Rn ~0.1–10 on QuantStudio; "intercept between 0.09 and 0.40 RFU" even on Biomark, https://cran.r-project.org/web/packages/PCRedux/refman/PCRedux.html), subtracted curves have early-cycle mean ≈ 0 with sign-symmetric noise and negatives; (b) subtraction footprint — early-cycle values exactly linear/near-constant at 0 (curve-fit) vs natural noise; (c) scale test — Rn-like vs RFU vs normalised 0–1 (Brintz-style); (d) ΔRn vs Rn by QuantStudio sheet header; (e) plate-wide consistency — mixture of raw and subtracted wells = per-well override. Output: provenance fact in record; Decision Card: "These curves were baseline-subtracted by CFX Maestro before export. Options: re-export with 'No Baseline Subtraction'; analyse with vendor baseline accepted (efficiency from plate dilution series only); stop." Agent: `qpcr_signal_provenance(study)`; `qpcr_plan` can refuse per-well efficiencies on subtracted data.
- Feasibility: 3–5 days; test data `ruijter` ds_94_4 raw (CC BY 4.0) plus synthetic subtraction/ROX division; PCRedux/qpcR sets across LC 1.0, LC480, ABI 7700/7300, CFX96/384, Chromo4, iQ5, Biomark (GPL — tests only). Hardest: assays with genuinely tiny baselines and vendor curve-fit subtraction leaving smooth non-zero residuals — report "unknown" rather than guess.
- Why qPilot: "same open method on raw curves" is the promise; a wrong input silently breaks it; fact + card + MCP gate.
- Risks/confidence: false alarms — per-vendor presets and "declare and move on". Confidence **high** pain/buildability, **medium** false-positive rate.

**D2. Plate Residual Map — position-aware QC with spatial statistics and cause-shaped hints** (rank 2)
- Persona: PhD student running 384 plates weekly with adhesive seals on a six-year-old block; core manager with four instruments of three makes.
- Pain evidence: 96-replicate SD 1.91 on 7900HT vs 0.34 on CFX96 (https://pmc.ncbi.nlm.nih.gov/articles/PMC4578049/); 96% of 1,894 384-well plates showed spatial bias worth 22% of variance (https://academic.oup.com/bioinformatics/article/32/13/1959/1742942); Bio-Rad edge rule (https://www.bio-rad.com/webroot/web/pdf/lsr/global/english/primePCR/LIT10026370.pdf). Cost estimate: one re-run per affected plate (~€100–300 reagents plus a day, labelled estimate), or a gradient that becomes a "difference between groups" when groups are pipetted by column.
- Exists: vendor per-well flags, no spatial stats, no trend; HTS tools (B-score, Moran's I, LISA) not for qPCR, don't consume RDML; qpcR KOD/SOD position-blind and GPL.
- Feature: inputs RDML (react id → row/column via `pcrFormat`), LinRegPCR per-well outputs, layout. Steps: within-replicate-group residual r = log N0 − group median; global Moran's I with rook/queen adjacency and permutation null shuffling within replicate groups (https://academic.oup.com/bioinformatics/article/32/13/1959/1742942); local Moran (LISA); row/column median polish (B-score, Brideau 2003, DOI 10.1177/1087057103258285) and border-vs-interior Wilcoxon; edge index; kinetic outliers by Bar 2003 Z-test and Sisti-2010 Mahalanobis (https://doi.org/10.1186/1471-2105-11-186). Output: residual heatmap with p-values; facts like "plate 3: Moran's I = 0.31 (p < 0.001), edge index +0.42 Cq-equivalent"; cause-shaped hint (smooth gradient → thermal; outer-ring late-cycle drift → evaporation; isolated wells → bubble/contamination). Decision Card only when robustness engine shows conclusion could flip (edge wells excluded / row-column fixed effect / nothing). MCP: `qpcr_plate_qc(study, plate)`.
- Feasibility: 2–3 weeks; numpy/scipy; validation on `ruijter` ds_380 (380 technical replicates with well IDs, CC BY 4.0, https://github.com/ramiromagno/ruijter), htPCR 95×96 grid, synthetic gradient injection as public acceptance test. Hardest: layout/position confounding — group-wise residuals, layout-respecting permutations, refuse to attribute when confounded.
- Why qPilot: per-well raw-curve facts, replicate structure, robustness engine, Decision Cards, domain-agnostic plate model.
- Risks/confidence: over-flagging small plates (require minimum group sizes). Confidence **high** feasibility/fit, **medium** on how often research plates show actionable effects.

**D3. Instrument Passport — Levey-Jennings/Westgard trending per instrument across the lab's records** (rank 3)
- Persona: core manager with 3–6 instruments; lab head with a five-year-old QuantStudio. Weekly "is instrument B drifting?"; semi-annually "is the $1,500 plate worth it?".
- Pain evidence: dye calibration every 6 months because components age (https://documents.thermofisher.com/TFS-Assets/LSG/manuals/4489821.pdf); "Block Cycle Count and LED Life" shown only on the touchscreen (https://www.ffclrp.usp.br/divulgacao/emu/real_time/manuais/QuantStudio3_5_InstallUseMaint_UG.pdf); plates $1,136–1,508 single-use; clinical labs have "Levy Jennings charts, Westgard rules" (https://www.ugentec.com/fastfinder); inter-instrument offsets 4–5 cycles. Cost estimate: undetected drift invalidates weeks of plates.
- Exists: vendor reminders/history reports; verification plates (pass/fail); IQ/OQ contracts; closed clinical software.
- Feature: inputs all Analysis Records; per run instrument identity, date, block, control sample types, per-assay efficiency, baseline level/slope, plateau, replicate SD, D2 indices, passive-reference level. Charts per instrument × assay × control: Levey-Jennings with limits from ≥ 20 points (https://www.westgard.com/lesson12.htm), Westgard 1-3s, 2-2s, R-4s, 4-1s, 10x (https://www.westgard.com/mltirule.htm); NTC rate as p-chart; efficiency/baseline-slope EWMA with change-point; calibration events overlaid. Output "instrument passport" page; Decision Cards only when a rule fires on a control relevant to an open study. MCP: `qpcr_instrument_status(instrument)`.
- Feasibility: 3–4 weeks. Hardest: identifying the same control material and instrument identity across files (lab profile with naming rules; start with user-tagged controls).
- Why qPilot: only a tool storing every plate as a record can trend for free.
- Risks/confidence: small labs lack 20 control points ("learning limits"); lot changes cause false alarms. Confidence **high** for cores, **medium** single-instrument labs.

**D4. Between-run/instrument offset estimation by factor correction (Ruijter 2015) in the robustness grid** (rank 4)
- Persona: any study over more than one plate or instrument (most); cores pooling client plates.
- Pain evidence: "6-times difference between runs 2 and 5"; calibrator error "propagated to all samples in the plate" (https://www.gene-quantification.de/ruijter-et-al-variation-multi-plate-pcr-bdq-2015.pdf); platform offsets 4–5 cycles (https://pmc.ncbi.nlm.nih.gov/articles/PMC7151141/); dividing Cq values to correct between-plate variation is wrong (https://pmc.ncbi.nlm.nih.gov/articles/PMC8229287/).
- Exists: calibrator samples (must succeed on every plate); Factor-qPCR (standalone, licence not found); qbase+ (commercial); nothing in LinRegPCR/rdmlpython.
- Feature: implement Y_nj = F_n × (Y_mean + C_j + error): per-pair geometric mean of ratios over overlapping conditions; nested substitution for missing pairs (Eq. 3) with the paper's warning "when more than 2 rounds of substitution are required ... run another plate"; run factor (Eq. 4); corrected N0 = N0/F_n (Eq. 5); efficiency-corrected Cq (Eqs. 7–12). Additions: bootstrap CI on each F_n; log(F_n)/log(E) as Cq-equivalent offset; design check before the run ("plates 5 and 6 share no conditions"); grid dimension {no correction, calibrator, factor}. MCP: `qpcr_run_factors(study)`.
- Feasibility: 1–2 weeks; equations in paper (reimplement under Apache-2.0); validation on the paper's 6-plate example and synthetic factors on `ruijter` data (CC BY 4.0).
- Why qPilot: multi-plate whole-study analysis is the core; robustness engine is where "does the correction matter" belongs.
- Risks/confidence: when plates coincide with groups the factor absorbs biology — refuse confounded designs. Confidence **high**.

**D5. Verification-plate re-analysis — $1,200 RNase P / CFX Qualification plate as a position-resolved uniformity map and trend** (rank 5)
- Persona: cores and QA-minded labs running Thermo RNase P plates every six months or Bio-Rad Qualification plates.
- Pain evidence: pass/fail only; Thermo "automatically adjusts the threshold and omits a defined number of wells" (https://www.ffclrp.usp.br/divulgacao/emu/real_time/manuais/QuantStudio3_5_InstallUseMaint_UG.pdf); Bio-Rad "1-click pass/fail" (https://www.bio-rad.com/sites/default/files/webroot/web/pdf/lsr/literature/Bulletin%206323.pdf); position information discarded though layout is fixed.
- Exists: vendor report PDF; IQ/OQ reports.
- Feature: import verification run; apply known layout (Thermo STD 1,250–20,000 copies, Unknown A 5,000, Unknown B 10,000, NTC; Bio-Rad 5-point curve, two unknown groups, NTCs); recompute vendor criterion exactly ([(CT_A) − 3σ_A] > [(CT_B) + 3σ_B]; 2-fold at 99.7%) with and without omitting wells; per-well efficiency/N0/plateau maps, D2 statistics, slope/intercept; store as passport event (D3) and trend over years. Decision Card: "Verification passed with 3 omitted wells, all in column 24; edge index +0.6 Cq. Options: accept; schedule uniformity calibration; investigate seal/block." MCP: `qpcr_verification_report(run)`.
- Feasibility: ~1 week on top of D2/D3. Hardest: obtaining per-cycle verification data (.eds export) and plate variants.
- Why qPilot: raw-curve engine + plate model + record + trend; credible for cores.
- Risks/confidence: qPilot's numbers will differ slightly from vendor's (present both). Confidence **medium–high**.

**D6. Well Signal Integrity — multi-channel artefact signatures with evidence cards** (rank 6)
- Persona: bench scientists reviewing a plate; agents deciding well trust.
- Pain evidence: Thermo tells users to inspect every well for "spikes, dips, and/or sudden changes" and confirm passive reference "remains unchanged" (https://www.ffclrp.usp.br/divulgacao/emu/real_time/manuais/QuantStudioDesign_Analysis_Desktop_Software_UG.pdf); "bubbles affect all dyes", baseline drift ← probe degradation/bubble/BHQ reduction (https://blog.biosearchtech.com/thebiosearchtechblog/bid/63622/qpcr-troubleshooting); Rotor-Gene "Slope Correct" rationale; forum users can't tell bubble from seal failure from detector fault (https://www.researchgate.net/post/Strange_qPCR_amplification_plot_curves_Can_I_omit_wells_that_have_unusual_RFU_values_What_causes_such_a_pattern_in_the_RFU_output). Cost estimate: minutes per plate; inconsistent exclusions.
- Exists: vendor per-well flags (not trended/explained); PCRedux features slope_bg, sd_plateau, autocorrelation, hookreg (MIT, R, https://cran.r-project.org/web/packages/PCRedux/refman/PCRedux.html); no published validated bubble/evaporation detector (gap).
- Feature: inputs multi-channel per-cycle data (QuantStudio Multicomponent/Raw Data sheets, CFX per-fluorophore RFU, LC480 per-channel) via vendor-import path (RDML carries only the reporter). Signatures: (a) step/bubble — first-difference outlier > k × MAD at same cycle in ≥ 2 channels incl. passive reference; (b) spike/dip single-cycle one channel; (c) ground-phase drift slope cycles 3–12; (d) late-cycle drift (plateau slope last five cycles + passive-reference trend) reported with D2 edge index → evaporation hint; (e) passive-reference anomaly (ROX far from plate median or ≈ 0, EPFL ranges); (f) hook. Output per-well integrity facts; Decision Card only when the well changes a conclusion; card shows multi-channel trace.
- Feasibility: 2–3 weeks after vendor capture; acceptance tests by synthetic injection into CC BY data plus opt-in labelled commons. Hardest: no public ground truth — report "signature present", never diagnosis.
- Why qPilot: eyeballed exclusion → recorded, reasoned, re-runnable decision; per-well trust signal for agents.
- Risks/confidence: depends on vendor multi-channel exports (RDML-only users get reduced set); over-engineering before D1–D3. Confidence **medium**.

Note's ranking rationale: D1 (days, prevents silent wrong answers), D2 (weeks, broad pain), D3 (cores), D4 (published method, multi-plate norm), D5 (narrower persona), D6 (depends on vendor capture, no ground truth).
