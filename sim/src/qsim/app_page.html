    How to read the screen

    • Reasonable analyses: every combination of choices a careful lab could defend, with your question fixed. Common shortcuts are shown but kept out of verdicts.
    • Same answer in N of a hundred: how often reasonable analyses give the same call as your planned analysis, per hundred.
    • Fewest samples that change it: the smallest set of samples whose removal changes the call.
    • The fold-change line: the size a change must reach before it is called.
    • Planned analysis: the analysis fixed before results were seen. The engine reproduces qPilot exactly here.

    Has it been tested?

    Checks against known answers, planted faults and data with no real difference, read from the run's files.

      What comes next

      • Other designs. Choose your own marker gene, groups and reference genes, so any lab's RDML file can be opened, not only two-group studies like this one.
      • Digital-PCR truth. Score every analysis against digital PCR, on more than one instrument.
